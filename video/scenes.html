How it was measured
  • 18 synthetic memory logs in Observational Memory format, 3 planted facts each (18 fact types x 3)
  • Mastra's own Reflector prompt code, bundled unmodified from two refs: main and PR #26465 (open)
  • Compression levels 1 to 4, one call per log per level per ref, temperature 0
  • Survival counted by code only (token and same-line rules). No LLM judge
